Privacy Policy

Application: Malin's Homelab Oura Connector
Last updated: 13 November 2026

What this application is

This is a private, non-commercial application for personal use only. It is run by one person (the owner) on their own home server to view their own Oura Ring data in a personal dashboard. It is not offered to the public and has no other users.

What data is accessed

With the owner's consent through Oura's OAuth login, the application reads the owner's own Oura data, such as daily activity (steps, calories), workouts, sleep and readiness. It only reads data and never writes to or changes the Oura account.

How data is used and stored

  • Data is used only to show the owner their own health and activity trends.
  • OAuth tokens and any cached data are stored only on the owner's private home server.
  • Data is never sold, shared with third parties, or used for advertising.

Retention and deletion

The owner can revoke access at any time in the Oura account settings. Revoking access stops all data collection, and stored tokens and cached data are then deleted from the home server.

Your rights (GDPR)

The only person whose data is processed is the owner, who has full control over it. Questions can be sent to the contact email registered with this application in the Oura developer portal.
